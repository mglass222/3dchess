# Board Wood Textures

These SVG image textures are generated project assets for the chessboard:

- `maple-grain.svg`: light square directional flat-sawn maple grain.
- `walnut-grain.svg`: dark square and frame directional flat-sawn walnut grain.

They are intentionally local generated assets so the project does not depend on
login-gated, preview-only, or unclear-license texture sources.
