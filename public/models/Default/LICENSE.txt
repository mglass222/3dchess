Default Staunton set — model credits

The pawn, rook, bishop, queen, king and knight pedestal are original geometry
created for this project. Rebuild them with: npm run models:build

The knight head is adapted from:
"Realistic Chess Set 3D Model" by noob-3d
https://sketchfab.com/noob-3d
